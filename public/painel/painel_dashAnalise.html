Como está o uso?

Como ler: a linha é a média de cada 5 minutos. A faixa azul vai do menor ao maior valor daquele intervalo. Ponto vermelho = o maior valor passou do limite.

Qual servidor está pior?

Como ler: a porcentagem dos intervalos de 5 minutos em que o servidor passou do limite. Clique para ver os detalhes dele.

    Quando fica mais pesado?

    Como ler: cada linha é uma hora e cada quadradinho são 5 minutos. Azul = tranquilo, vermelho = pesado. A borda branca marca o pior momento.

    0%100%

    Quanto tempo em cada estado?

    Como ler: OK = longe do limite. Alerta = a menos de 10 pontos do limite. Crítico = passou do limite.

    Como foi cada hora?

    Como ler: cada barra é o maior valor da hora. Barra vermelha = a hora passou do limite. A linha branca é a média da hora.
